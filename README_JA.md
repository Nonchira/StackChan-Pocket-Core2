# StackChan Pocket はじめての導入ガイド — M5Stack Core2専用

## 対応機種：M5Stack Core2専用

現在の配布ファームと動作確認対象は **M5Stack Core2専用** です。CoreS3向けファームとしては使用しないでください。

**Androidアプリは、USB接続対象をCore2のCP2104／CH9102Fに限定しています。** CoreS3のUSBは方式が異なるため、現在のUSB接続対象には含まれません。Wi-FiについてもCoreS3での本配布版の動作保証はありません。

**本リリースはM5Stack Core2専用です。** AndroidアプリのUSB接続対象はCore2のCP2104／CH9102Fに限定しています。CoreS3はUSB未対応、Wi-Fi接続を含む実機動作は未検証です。今後、実機検証のうえ対応を検討します。Core2用ファームをCoreS3へ書き込まないでください。


対象：Androidアプリ 0.3.45 / M5Stack Core2ファーム 0.3.32

スマホが音声認識・会話の生成・読み上げ音声の生成を行い、Core2がマイク・スピーカー・表情・サーボを担当します。スマホのマイク／スピーカーも選択できます。初回のダウンロードにはインターネットが必要です。準備後の会話はオフラインで使用できますが、天気・ニュースの新規取得には回線が必要です。

## 最初に必要なモデルをダウンロード

**APKだけでは会話できません。次の4ファイルを別途取得して、スマホのアプリへ取り込んでください。** モデルは配布ZIPに含まれません。

|取り込みボタン|選ぶファイル|入手先・役割|
|---|---|---|
|音声認識 ONNX|`model.int8.onnx`|[SenseVoice配布アーカイブ](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17.tar.bz2)。声を文字に変換|
|音声認識 tokens.txt|`tokens.txt`|上と同じアーカイブ内のファイル|
|Silero VAD ONNX|`silero_vad.onnx`|[ダウンロード](https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/silero_vad.onnx)。話し始め・話し終わりを判定|
|LLM .litertlm|`gemma-4-E2B-it.litertlm` **または** `gemma-4-E4B-it.litertlm`|[E2B配布ページ](https://huggingface.co/litert-community/gemma-4-E2B-it-litert-lm/tree/main)／[E4B配布ページ](https://huggingface.co/litert-community/gemma-4-E4B-it-litert-lm/tree/main)。返答を生成|

**LLMはどちらか1つです。** E2Bは軽快さ、E4Bは回答品質を重視する場合の候補です。この手順では名前に`-web`や`-gpu`の付かない上記ファイルを選びます。GGUFの拡張子を変更しても使えません。

1. SenseVoiceの`.tar.bz2`を展開し、`model.int8.onnx`と`tokens.txt`を取り出します。`.tar`が出たらもう一度展開します。VADとLLMは展開不要です。
2. スマホの内部ストレージに`Download/StackChanModels`フォルダを作り、4ファイルを保存します。PCで取得した場合はUSBの「ファイル転送」でコピーします。**Core2のSDカードには入れません。**
3. アプリの処理を終了し、設定→端末内モデル→「モデルの取り込みを開く / 閉じる」で、各ボタンから対応するファイルを選びます。
4. 各ファイルの取り込み完了を待ち、4つ揃ったら「モデルを読み込む」を押します。

保存先は上記以外でも選択できます。取り込み時にアプリ内へコピーされるため、元ファイルとコピーの両方に空き容量が必要です。元ファイルは再導入用に保管してください。

**読み上げ用には、Androidの音声エンジン設定でオフライン日本語音声も準備します。** これは上記4ファイルとは別です。

展開方法・保存場所の図・取り込み・モデル変更の詳細は **[モデルの取得・保存・取り込み](MODELS_JA.md)** を参照してください。

## 1. 用意するもの

- M5Stack Core2と、対応するスタックチャン機構。サーボは本版のPORT A接続構成に合わせます。
- Android 13以降・64bit ARMのスマートフォン。実機確認機種はPixel 9 Pro XLです。他機種で同じ速度・動作を保証するものではありません。
- データ通信対応USBケーブル。充電専用ケーブルでは接続できません。必要に応じUSB OTGアダプター／給電対応ハブ。
- Core2へ書き込むためのPC、VS Code、PlatformIO IDE拡張機能。
- スマホの空き容量。モデル原本とアプリへの取り込みコピーの両方が必要です。ダウンロード画面の合計サイズの2倍以上に、展開用の余裕も確保してください。

本編はローカル動作専用ですが、Termux、GPT APIキー等、SDカードは不要です。AIｽﾀｯｸﾁｬﾝ2とは別のファームです。

## 2. 配布物を展開する

ZIPはPCの短い英数字のフォルダへ展開してください。例：`C:\StackChan`。これは例であり指定ドライブである必要はありません。ZIPを開いたままビルドせず、必ず展開します。

- `StackChan-Pocket-0.3.45.apk`：スマホにインストールするアプリ。
- `Core2_Source`：Core2に書き込むPlatformIOプロジェクト。
- `Android_Source`：アプリを自分で改修・ビルドする方向け。通常の利用では開く必要はありません。
- `MODELS_JA.md`：モデルのダウンロードと取り込み方法。
- `FAQ_JA.md`：困ったときの確認手順。

## 3. Core2へ書き込む

1. VS CodeにPlatformIO IDE拡張をインストールします（初回は関連ツールの取得に時間がかかります）。
2. Core2をスマホから外し、データケーブルでPCへ接続します。
3. VS Codeの「フォルダーを開く」で、この配布物の`Core2_Source`を選びます。直下に`platformio.ini`が見えることを確認します。
4. PlatformIOのProject Tasksで`m5stack-core2-audit`→General→Buildを実行します。
5. Build成功後にUploadを実行します。Buildだけでは本体は更新されません。
6. ポートを選ぶ場合は、そのPCでCore2を接続した時に現れるポートを選択します。特定のCOM番号に固定しません。

シリアルモニターがポートを使っている場合は閉じてからUploadします。任意の`firmware.bin`をアドレス0へ直接書き込まないでください。本配布はPlatformIOによる書き込みを基本とします。

## 4. スマホにアプリを入れる

APKをスマホのDownloadフォルダへコピーするか、スマホでダウンロードし、「Files」などのファイルアプリから開きます。インストール元の許可を求められたら、そのファイルアプリに必要な許可を与えてインストールします。これは開発者向けのdebug署名APKで、Playストア配布ではありません。

同じ署名の旧版からは上書き更新します。アンインストールすると、取り込んだモデルとアプリ設定が失われます。

続いて`MODELS_JA.md`に従って4ファイルを取り込み、日本語の読み上げ音声を準備してください。

## 5. 接続する

### USB

1. Core2のBボタンを約2秒長押ししてメニューを開きます。「通信方式」でUSBシリアルを選択・決定します。本体は再起動します。
2. スマホをUSBホストとしてCore2に接続します。スマホから給電するか、対応する給電ハブを使用します。
3. アプリの設定→Core2への接続でUSBシリアルを選び、接続／再接続を押します。
4. USBデバイスへのアクセス許可を承認し、「Core2 USB接続済み」を確認します。

スマホの開発者モードやUSBデバッグは、このUSB接続のためには不要です。

### Wi-Fi

1. Core2の通信方式をWi-Fiへ変更します。本体が再起動します。
2. スマホのWi-Fi設定で`StackChan-Direct`へ接続。初期パスワードは`stackchan123`です。これは製品の共通初期設定で、自宅Wi-Fiの情報ではありません。
3. 「インターネット接続なし」と表示されても、このWi-Fi接続を維持します。
4. アプリ側もWi-Fiを選択し、本体IPを`192.168.4.1`として接続します。

このWi-FiはスマホとCore2の直接通信用です。天気・ニュースには別途モバイル回線などが必要です。

## 6. 最初の会話

モデルを読み込み、Core2への接続状態を確認します。設定でマイクとスピーカーの出力先をそれぞれ選べます。最初は「Core2で読み上げテスト」で音量を確認すると切り分けが簡単です。

Core2の顔の上側中央をタッチして、一回会話を開始します。操作音とマイク表示を確認してから話します。一回会話は話し終わった後の無音で終了し、返答後は待機をオフにします。「聞き取りの区切り」は録音全体の長さではなく、終了と判断する無音時間です。連続会話はアプリから選びます。

B短押しは天気、B長押しはメニューです。音量・通信方式・サーボの正面補正などはメニューから設定します。ニュースの件数・カテゴリー、天気の地点はアプリで設定できます。取得した情報を使い、モデルが最新ニュースを知っている前提では動作させません。

## 設定はスマホ、本体は簡易操作

天気の地点登録・広域の設定、ニュースの件数とカテゴリー、マイク／スピーカーの選択など、詳しい設定はスマホアプリから行ってください。Core2のメニューは手元で使う簡易操作用です。

| やりたいこと | 操作する場所 |
|---|---|
| 天気の地点を追加登録する | スマホの天気設定 |
| 登録した地点を選ぶ／広域で複数地点を読む | スマホの天気設定 |
| 設定した天気を読み上げる | Core2のB短押し |
| プリセット2地点のうち1地点へ切り替える | Core2のB長押し→天気予報地点 |
| 聞き取り元を変える | スマホのマイク設定、またはCore2のマイク選択 |
| 音を出す先を変える | スマホのスピーカー設定 |

Core2の天気予報地点メニューは、大阪府・東京都から1地点を選ぶ仕様です。スマホで追加した地点の一覧を表示するメニューではありません。本体で地点を選択すると、スマホ側も単一地点に切り替わり、広域設定は解除されます。追加地点や広域を利用する場合はスマホ側で選択し、本体ではB短押しで読み上げてください。

「マイク選択」は声を聞き取る機器の選択です。「スマホのマイク」にしても再生先は変わりません。スマホから声を出したい場合は、アプリの設定→「スピーカー（マイクとは別に選択）」→「スマホ本体のスピーカー」を選んでください。Core2本体にはスピーカー出力先の切り替えメニューはありません。

## 声の標準値

速さ **1.30**、高さ **1.50** を初期値とします。調整範囲は速さ0.60～2.00、高さ0.70～2.00、いずれも0.05刻みです。既存の保存済み設定は上書きしません。更新後に新しい標準へ合わせるには、設定→声の速さ・高さ→「標準に戻す（速さ1.30・高さ1.50）」→「保存して試聴」または「保存して閉じる」を押してください。「標準に戻す」だけでは保存されません。Core2ファームの更新は不要です。

## 実行方式と速度設定

CPU／GPUの選択肢を維持しています。初期値はCPU。GPUは端末により対応・速度が異なります。NPUとは別の実行方式です。

GPUを試す場合は設定→端末内モデル→LLMの実行方式でGPUを選び、「アプリの処理を終了」→モデル読み込み→再接続→会話開始の順に操作してください。変更しただけでは読み込み済みエンジンは切り替わりません。GPUで読み込めない場合はCPUへ戻し、同じ手順で読み込み直します。

「最初の読点から話す（比較用）」と「会話の処理結果を再利用（比較用）」は初期OFFです。速度を試す場合はONにできます。読点の設定は最初の自然な区切りで読み上げを始める機能です。再利用は完了済みの履歴が一致する場合だけ働きます。詳しくは[操作説明](USAGE_JA.md)と[FAQ](FAQ_JA.md)をご覧ください。

## 現行版と確認範囲

Android 0.3.45／Core2 0.3.32。モデル・個人設定・会話履歴は配布物に同梱していません。CPU/GPU設定、マイク／スピーカー選択、USB／Wi-Fi、天気・ニュース、声の調整などを含みます。今回の配布整理では実行ファイルを再変更していません。

天気プリセットは大阪府・東京都です。大阪府は府の予報、東京都は東京地方の予報で、伊豆・小笠原諸島を含みません。旧京都・奈良の選択は大阪府へ移行し、自分で追加した地点は保持します。更新直後は一度オンラインで予報を取得してください。

Pixel 9 Pro XLでGPU会話・履歴再利用と、LLM開始から音声送信まで1秒未満の例が報告されています。毎回1秒未満や全端末での動作を保証するものではありません。実際の発音開始・無音判定・ASR込みの時間とは異なります。

USBの長時間音声再生と他アプリ切り替え後の会話復帰は先行版で実機確認済みで、該当処理を維持しています。画面消灯後の長時間運用、切断復帰、全音声エンジン・全機種・GPU再利用の長時間安定性について、一律に確認済みとはしていません。

既にCore2 0.3.32なら本体更新不要です。以前の4地点メニューのファームから移行する場合は本体も更新します。APKは同じ署名の版へ上書き更新し、モデルは通常再取り込み不要です。旧配布物を保管してください。

初めて使う方はREADME→MODELS_JA→USAGE_JAの順にお読みください。困ったときはFAQ_JA、ソースのビルドはDEVELOPMENT_JA、由来・謝辞はCREDITS_JAを参照してください。


## Core2の電池表示
電池表示は初期OFFです。B長押しメニューの「バッテリー表示」でON／OFFを切り替え、本体に保存できます。詳細は[操作方法](USAGE_JA.md)を参照してください。


## USB-C直結で認識しない場合：OTG接続

データ通信対応のUSB-Cケーブルで直結してもCore2を認識しない場合は、次の構成を試してください。

**Androidスマホ → USB OTGアダプタ（USB-Cオス／USB-Aメス）→ USB-A・USB-Cデータ通信対応ケーブル → Core2**

スマホ側にOTGアダプタを接続し、アプリの接続／再接続を押します。USBアクセス許可が表示されたら許可してください。開発者モード・USBデバッグは必要ありません。充電専用ケーブルでは通信できません。

Core2 AWSではUSB-C直結でき、別の白いCore2ではOTGアダプタ経由で接続できた利用者報告があります。個体・ケーブル・端末の組み合わせによる実績であり、「AWSはアダプタ不要」「白いCore2は必須」という機種別保証ではありません。OTGアダプタでもすべての組み合わせの動作を保証するものではありません。
